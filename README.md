# Video Downloader

A desktop video downloader powered by yt-dlp, with support for YouTube and many other sites supported by yt-dlp.

## Requirements
- Python 3.11+
- FFmpeg (recommended for merging audio/video and format conversion)

## Run

```powershell
python -m pip install -r requirements.txt
python app.py
```

Only download content you own, have permission to download, or that the site's terms permit. This project does not bypass DRM, paywalls, or access controls.
